<h1>AOA Manimations</h1>

<h2>Description</h2>

Data Structures and Algorithms (DSA) are crucial for coders as they form the foundation for writing efficient and optimized code, enabling problem-solving in real-world scenarios. Understanding DSA can be challenging due to its abstract concepts, mathematical complexity, and the need for rigorous practice to master algorithmic thinking. However, mastering DSA is essential for tackling coding interviews and building scalable software solutions.

The project mainly focuses on the working of various algorithms, bringing 15+ complex algorithms to life through simplified animations.

It covers the concepts of searching and sorting Algorithms, and problem-solving techniques including greedy algorithms, dynamic programming, and backtracking methodologies.

The project is easy to use and can work dynamic input. However, it takes time to render the animations in the mp4 output file.

<h2>How to use?</h2>

Simply run a file using the command <strong>manim -p {{file-name}}</strong>
